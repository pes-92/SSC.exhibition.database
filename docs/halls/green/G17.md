### 1.3 체험
##### 체험1) 3D로 세계적 건축물을 확인하고 적용된 수학적 원리 알아보기
1. 건축물 카드의 앞면을 체험대 위에 올려 건축물의 모습을 3D 그래픽으로 확인한다.
2. 건축물 카드를 손 위에 올려보고 좌우로 움직여본다.
3. 건축물 카드의 뒷면을 체험대 위에 올려 해당 건물의 정보를 확인한다.
4. 어떤 건축적 수학원리가 적용되었는지 확인한다.
5. 좌측 패널에서 해당 수학적 원리를 찾아보고 내용을 살펴본다.
