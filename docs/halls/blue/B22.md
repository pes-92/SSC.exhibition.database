### 1.3 체험
##### 체험1) 전동기 동력 전달과정 이해하기
1. 지하철을 움직이는 유도전동기의 구조를 살펴본다.
2. 시작 버튼을 누른다
3. 유도전동기 앞의 LED의 깜빡임에 맞춰 시작 버튼을 5회 누른다.
4. 유도전동기의 회전자가 회전할 때 도시 배경 그래픽 아래에 위치한 지하철 모형이 어떻게 되는지 확인한다.
