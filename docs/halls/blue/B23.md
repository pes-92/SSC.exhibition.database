### 1.3 체험
##### 체험1) 제트엔진 전달과정 이해하고 제트엔진 작동하기
1. 비행기의 동력인 제트엔진의 내부 구조를 살펴본다.
2. 시작 버튼을 누른다.
3. 비행기가 출발한 후, 속도 레버로 속도를 조정한다.
4. 비행기가 최고점에 도달했을 때, 속도 레버의 작동을 멈춘다.
