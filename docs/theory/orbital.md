<h1>오비탈(확인요)</h1>

오비탈 29) 현재의 원자모형은 보어의 원자모형에서의 문제점을 개선해서 나오게 되었다. 양자역학의 관점에서 보어의 원자모형은 전자의 궤도가 사실상 원자 전체 크기만큼의 오차를 가져 정확한 궤도를 알아낼 수 없다.(하이젠베르크의 불확정성 원리) 입자로써 전자의 위치를 표현하기 어렵기 때문에 나온 대안이 전자를 파동으로써 보는 방법이다 (드브로이 가설에 따른 드브로이 식). 전자를 파동으로 보게 되면서 원자구조에 대한 슈뢰딩거의 양자역학 모델은 파동방정식이라는 수식으로 표현할 수 있다. 이 파동방정식의 정답 (해) 가 바로 오비탈이다. 오비탈은 확률적으로 전자가 발견되는 공간을 의미하기도 한다. 오비탈은 수학 식의 결과물이므로, 이 결과물을 얻기 위해서는 수식에 들어가는 몇 가지 매개변수에 대해 알 필요가 있다. 1. 주양자수 (n) 1, 2, 3 과 같은 양의 정수이고, 오비탈의 크기와 에너지준위 (양) 를 결정한다. 이 주양자수는 우리에게 익숙한 전자껍질의 개념과 유사하다. 주양자수가 커지면 전자가 핵으로부터 멀리 있다는 뜻이므로, 오비탈의 크기가 커진다. 예를 들어 수소나 헬륨과 같이 1 개의 전자껍질을 가진 경우 주양자수 1 인 오비탈만을 가진다. 반면 전자껍질이 두 개인 리튬 등의 원자는 주양자수 1, 그리고 주양자수 2 인 오비탈을 모두 가진다. 2. 부양자수 (각운동량 양자수, l) 주양자수 n 에 대해 0 ~ n -1 개의 개수를 가지게 된다. 주양자수 속의 작은 전자껍질이다. 해당 주양자수 내에 오비탈이 지닌 각운동량 (회전하는 물체가 지닌 에너지량) 에 따라 그 수가 달라지고, 각 껍질은 s, p, d, f 와 같이 알파벳으로 표기된다. 각운동량 양자수 0 1 2 3 4 부껍질 표기 s p d f g 3. 자기 양자수 (m l) 부양자수 l 에 대해 –l ~ +l 사이의 정수로 된 값을 가진다. 입체 공간상에서 오비탈의 방향을 의미한다. 예를 들어 s 오비탈의 경우 구형으로, 부양자수가 0 이기 때문에 자기 양자수도 0 만 가지게 되지만 p 오비탈의 경우 -1, 0, 1 총 세 가지를 가지게 된다. n l m l 오비탈 표시 주껍질 속 오비탈 수 들어갈 수 있는 전자의 수 1 0 0 1s 1 2 2 0 0 2s 4 8 1 -1, 0, 1 2p 3 0 0 3s 9 18 1 -1, 0, 1 3p 2 -2, -1, 0, 1, 2 3d 4 0 0 4s 16 32 1 -1, 0, 1 4p 2 -2, -1, 0, 1, 2 4d 3 -3, -2, -1, 0, 1, 2, 3 4f
