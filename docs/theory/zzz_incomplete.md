내용작성

## 태그 작성 방법

전시물, 이론, 해설 문서에 태그를 달 때는 문서 안에 아래 형식으로 작성한다.

```html
<div class="doc-tags" data-tags="광학, 반사, 빛, B전시실"></div>
```

- 태그는 쉼표로 구분한다.
- 화면에는 `#광학`, `#반사`처럼 해시태그 형태로 표시된다.
- 태그 이름에는 `#`을 직접 붙이지 않는다.
- 교육과정 문서에는 태그를 달지 않는다.
- 새 태그를 추가한 뒤에는 로컬에서 `node scripts/generate-tag-index.js`를 실행해 태그 색인을 갱신한다.
