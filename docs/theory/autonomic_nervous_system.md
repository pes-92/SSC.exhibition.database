<h1>자율신경계(확인요)</h1>

자율신경계는 교감신경과 부교감 신경으로 구성되며,그 말단이 각종 내장 기관과 혈관에 분포되어 있어 주로 소화,순환,호흡 운동,호르몬 분비 등 생명 유지에 필수적인 기능을 맡고 있다. 교감 신경의 말단에서는 노르에피네프린이라는 신경 전달 물질이 분비되고,부교감 신경의 말단에서는 아세틸콜린이라는 신경 전달 물질이 분비되어 각 기관의 작용을 조절한다. 교감 신경은 척수의 가운데 부분에서 나오며,부교감 신경은 중뇌와 연수,그리고 척수의 끝부분에서 나온다. 교감 신경과 부교감 신경은 같은 내장 기관에 작용하여 한쪽이 작용을 촉진하면 다른 한쪽은 작용을 억제하는 길항 작용을 함으로써 몸의 내부 환경이 항상 일정하게 유지되도록 돕는다. 일반적으로 교감 신경은 우리 몸을 위기 상황에 대처하기 알맞은 상태로 만들어 주고,부교감 신경은 평상시 활동과 심신의 평온 상태를 유지시켜 주는 작용을 한다. 자율신경계 [^1] 55
