<h1>제곱근(확인요)</h1>

어떤 수 `x`를 제곱하여 `a`가 될 때, `x`를 `a`의 제곱근이라고 한다. 예를 들어 3을 제곱하면 9이므로 3은 9의 제곱근이고, -3을 제곱해도 9가 되므로 -3 역시 9의 제곱근이다.

양수의 제곱근에는 양수와 음수가 있고, 두 값의 절댓값은 서로 같다. 따라서 양수의 제곱근은 2개이다.
