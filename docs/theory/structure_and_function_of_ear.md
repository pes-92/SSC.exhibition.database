<h1>귀의 구조와 기능(확인요)</h1>

귀의 구조와 기능 [^1] http://study.zum.com/book/14578 귓바퀴 소리를 모음 외이도 귓구멍을 통해 들어온 소리가 지나가는 통로 고막 소리 (음파) 에 의해 최초로 진동하는 얇은 막 귓속뼈 (망치뼈, 모루뼈, 등자뼈) 고막의 진동을 증폭시켜 달팽이관으로 전달 귀 인두관 중이와 외이의 압력을 같게 조절 달팽이관 청각 세포가 있어 소리를 자극으로 받아들이는 곳 와우신경 청각 세포가 받아들인 자극을 대뇌로 전달 전정 기관 중력 자극을 받아들여 몸이 기울어지는 것을 감지 → 평형감각 기관 반고리관 몸의 회전을 감지 (관성)→ 평형감각 기관
